# Testes portáveis da preparação

Os testes desta pasta conferem integridade, rastreabilidade, transcrição e funções numéricas selecionadas, sem baixar rasters nem ajustar um novo modelo científico. Os testes originais do código selecionado continuam em `codigo/tests/`.

Execute na raiz:

```bash
python -m pytest testes -q
```

Os resultados efetivamente executados ficam no relatório de verificação da preparação. Testes de software não substituem as avaliações científicas do artigo.
